# Bookly — one-page React app

Single-page book discovery application built with React + Vite.

Features:
- Open Library API search
- Book cover images and details
- Search, sort and pagination
- Favorite collection saved in localStorage
- Random book discovery
- Responsive two-panel layout (catalog + spotlight)

Run:
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```

API endpoints used:
- https://openlibrary.org/search.json
- https://openlibrary.org/works/{workId}.json
- https://covers.openlibrary.org

No API key required. Public API rate limits may apply.
